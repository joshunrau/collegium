---
title: Overview
description: A multi-agent orchestration framework that runs LLM-backed agents as Mattermost bot users.
---

Collegium runs LLM-backed agents as bot users in your Mattermost workspace. They are persistent
colleagues, not job runners: each holds conversations with your staff, works a fixed set of
hand-written tools, and stops for human approval on every consequential action.

It is built for the work that isn't code — monitoring inboxes, drafting replies, researching on the
open web. There is no shell at the center of it: capability is granted tool by tool, every action
lands in a channel you can scroll, and when something goes wrong the agent stops and says so.

Collegium is not an autonomous agent platform. Agents do not run continuously, do not decide when to
act, do not write their own instructions, and do not create other agents. The design trades
throughput for supervisability, and that trade is deliberate.
