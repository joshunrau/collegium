---
title: Introduction
description: What Collegium is and what it is not.
---

Collegium runs LLM agents as bot accounts in your team's Mattermost workspace. Each agent has its own name, tools, and memory. Agents handle non-engineering work such as email, research, and follow-up tasks.

The design assumes that an agent's actions are visible to other people as soon as they happen and often can't be undone. Agents therefore work in channels where people can read every step. Any action that sends, writes, or runs something stops and waits for a person to approve it.

**Who it's for.** Small teams automating non-engineering work. To deploy it, you need to be comfortable with Docker and a JSON file.

**What it is not.** Collegium is not an autonomous agent platform and not a tool for writing software. Agents don't run continuously, decide when to act, write their own instructions, or create other agents.
