The Quickstart deployment has one agent. You can continue in three directions.

**Add an agent.** Declare a second agent in `config.json` and restart. The guide adds Theo, a researcher Clara can hand work to. See [Add an Agent](/docs/guides/add-an-agent).

**Write a plugin.** The guide builds a small plugin end to end: durable storage, an ungated read, a gated write, and settings. See [Write a Plugin](/docs/guides/write-a-plugin).

**Read the design.** Learn how activation, approval, and failure handling work and why. See [Design Overview](/docs/concepts/design-overview).
